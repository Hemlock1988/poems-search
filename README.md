# 📖 Поиск по стихам

CLI-инструмент для поиска строк в текстовых файлах. Ищет по одному или двум словам, подсвечивает найденное, показывает статистику.

## ✨ Возможности

- 🔍 Поиск по одному или двум словам
- 🎨 Цветной вывод в терминале
- 🖍️ Подсветка найденных слов
- 📊 Счётчик: сколько строк и в скольких файлах
- 🛡️ Обработка ошибок (нет папки, пустая папка, битые файлы)

## 🚀 Установка

Нужен [Node.js](https://nodejs.org) версии 18 или новее.

```bash
git clone https://github.com/Hemlock1988/poems-search.git
cd poems-search
```

## 📖 Использование

Поиск по одному слову:

```bash
node index.js дорога
```

Поиск по двум словам (найдёт строки, где есть хотя бы одно):

```bash
node index.js дорога луна
```

Без аргументов — выведет подсказку:

```bash
node index.js
```

## 📂 Структура

```
poems-search/
├── index.js          # основной скрипт
├── colors.js         # цветной вывод и подсветка
├── poems/            # мои стихи (txt-файлы)
├── .gitignore        # что не выкладывать
└── README.md         # этот файл
```

## 🛠️ Как это работает

1. Читает все `.txt` файлы из папки `poems/`.
2. Разбивает каждый на строки.
3. Ищет строки, содержащие искомые слова (регистр не важен).
4. Подсвечивает найденные слова жёлтым.
5. Считает статистику: строк и файлов.
